작성 요령
- **수량(1~99)** 처럼 범위가 있는 입력은 `경계 바로 아래 · 경계 · 경계 바로 위`(0, 1, 99, 100)와 형식이 다른 값(1.5, "2", null)을 모두 고른다.
- **재고** 는 `부족(재고-1 초과) · 딱 맞음 · 여유`, 상태는 `판매중 · 판매중지 · 품절` 로 나눈다.
- **성공 조건만이 아니라 실패 조건과 '실패했을 때 바뀌면 안 되는 것'(재고 · 장바구니 · 주문)** 도 케이스로 만든다.
